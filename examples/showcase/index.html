Which document format should I use?
  • HTML: supported web markup for publishing and exchange; arbitrary HTML/CSS is not preserved.
  • Markdown: a supported subset for text workflows, with tables and tasks; not full CommonMark/GFM conformance.
  • ART JSON: the A Rich Text document model for saving and re-editing. Valid JSON does not automatically mean a compatible rich-text document.
  • Plain text: content without formatting or document structure.
The json API value means ART JSON. Quill Delta and Editor.js JSON require conversion adapters.

Formats used by other editors
  • Quill: Delta JSON.
  • Tiptap / ProseMirror: schema-dependent document JSON and HTML.
  • Editor.js: blocks JSON with tool-specific data.
  • Lexical: serialized EditorState JSON; HTML and Markdown through helpers.
  • Slate: application-defined JSON nodes; custom serializers.
  • TinyMCE: HTML.
  • CKEditor 5: HTML, or Markdown through its GFM processor.
  • Notion: block API JSON; HTML or Markdown/CSV exports.
  • Google Docs: document API JSON, separate from file exports.
These are reference profiles, not bundled converters. See the format catalogue and official sources.


HTML, Markdown, ART JSON and plain text share one document model. Inline mode is a contextual toolbar; block menus and slash commands are planned separately.
