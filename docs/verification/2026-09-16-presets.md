## Compatibility and remaining scope

Default, Minimal and Document are appearance presets, independent of tool/view
configuration and extension bundles. Existing CSS variables and parts override
their defaults. No framework or dependency was added.

Table validation now rejects previously accepted malformed spans while retaining
ART v1 fields; consumers must repair those documents before loading. See
[ADR 0002](../adr/0002-table-grid-validation.md). Vertical merge/split and row/column
authoring remain open.

Physical-device, real-IME, screen-reader, broad RTL/reduced-motion, performance
and public-release gates remain open. Emulation is not physical-device evidence.
GitHub Actions remained disabled; all verification ran locally.
