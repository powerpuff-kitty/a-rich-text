# Automatic linking — local verification

Scope: optional standard-editing detection of URL/email tokens on typed spaces,
configuration guards, formatting preservation and atomic Undo/Redo. Enter,
paste/import, native composition and programmatic changes are not detection triggers.

- `pnpm verify`: 347 unit tests across 62 files, package policy, builds,
  typechecks, strict Vue example checks and bundle budgets passed.
- `node scripts/build-distribution.mjs`: standalone and integration examples rebuilt.
- `pnpm exec playwright test tests/browser/autolink.spec.ts --workers=1`:
  15 targeted cases passed across Chromium, Firefox, WebKit and mobile
  Chromium/WebKit emulation, default timeouts, no retries/skips (22.7 seconds).
- `pnpm verify:distribution`: all 26 tarballs passed inspection, isolated
  installation, DOM-free export imports and TypeScript consumer checks.
- The full browser suite was not repeated. Physical devices, real IME,
  screen readers and broader production checks remain open.

Earlier test runs exposed duplicate `mailto:` normalization (fixed with a unit
regression) and test caret placement assumptions. `End` stopped at a wrapped
line on mobile WebKit; an element-boundary Range also differed in WebKit. The
final test sets an explicit text-node caret before typing, matching the editor's
selection representation. No timeout/retry settings were changed.

GitHub Actions remained disabled. Local logs: `/tmp/art-autolink-verify.log`,
`/tmp/art-autolink-browser.log`, `/tmp/art-autolink-distribution.log`.
