## Reproduce

```sh
pnpm install --frozen-lockfile
pnpm verify:local
```

The command also packs every public package, checks licenses/readmes/export
targets and resolved workspace dependencies, installs the tarballs together in
an isolated offline npm consumer, imports every public entry without a DOM and
typechecks a consumer integration. Generated distributable files live under
`dist/browser/` and `dist/packages/`.

## Scope and limits

This establishes local integration readiness for the documented standard editor.
It is not a production release certification or an npm publication. GitHub Actions
remains disabled. Physical devices, real IMEs/mobile keyboards, manual screen
readers, RTL/reduced-motion coverage and broad performance/fuzz testing remain
separate release work. Paste tests simulate clipboard event delivery in real
browsers, not access to the OS clipboard. Keyboard toolbar tests activate a
focused native button; they do not replace a complete manual keyboard audit.

Known editing boundaries are documented in [getting started](../getting-started.md).
In particular, cross-block paste replacement and merged-cell editing are not
supported, and native composition reconciliation resets undo history.
