# Code of Conduct

Treat contributors, users and maintainers with respect. Be constructive about
ideas and code, make room for different experience levels, and respect privacy
and personal boundaries.

Harassment, discrimination, threats, sexualized attention, doxxing, impersonation,
and repeated unwanted contact are not acceptable. Do not post another person's
private information or retaliate against a good-faith report. Technical disagreement
is welcome; personal attacks are not.

This policy applies to repository issues, pull requests, discussions and other
project spaces, and to conduct while representing the project.

## Reporting and enforcement

Contact the repository owner, `powerpuff-kitty`, through an existing private channel.
If GitHub is the only available route, use GitHub's abuse-reporting tools for conduct
that violates its rules; avoid publishing sensitive incident details in an issue.
A verified private project reporting route must be established before public launch.

Maintainers assess reports in context, protect confidentiality as far as practical,
and may edit or remove contributions, give a warning, restrict participation or
remove a participant. Serious threats or repeated misconduct can lead to immediate
removal. Enforcement decisions should be proportionate and explained to affected
participants where doing so is safe. A maintainer involved in a report should not
be its sole reviewer; unresolved conflicts require an independent reviewer before
the project represents the matter as resolved.

Ask for reconsideration through the same private route, providing relevant context.
No participant is required to engage directly with someone they have reported.
